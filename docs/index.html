OWASP Top 10:2025

A01 — Broken Access Control CWE-639 / CWE-285

PROBLEMIDOR: any account is returned by id with no ownership check; admin area ungated. 
GET /a01/vuln/account/2        # leaks bob's card
SOLUTIONVerify caller owns the object (else 403); gate admin with @PreAuthorize("hasRole('ADMIN')"). 
GET /a01/secure/account/2      # 403; /a01/secure/admin/dashboard = ADMIN only

A02 — Security Misconfiguration CWE-16 / CWE-200

PROBLEMConfig dump exposes DB creds, JWT secret, internal hosts, versions. 
GET /a02/vuln/config
SOLUTIONReturn only {"status":"UP"}; SecureHeadersConfig adds CSP / X-Frame-Options / HSTS / nosniff. 
GET /a02/secure/config

A03 — Software Supply Chain Failures CWE-1104

PROBLEMDynamic versions, untrusted mirror, no checksums/scanning. 
GET /a03/vuln/dependency-check
SOLUTIONReject unpinned/denylisted deps; Gradle lockfiles, HTTPS-only repos, CI CVE scan. 
GET /a03/secure/dependency-check

A04 — Cryptographic Failures CWE-327

PROBLEMBase64 "encryption theatre" + MD5 for secrets/passwords. 
POST /a04/vuln/store?data=...
SOLUTIONAES-256-GCM (random IV per message) + BCrypt; key from config, never hardcoded. 
POST /a04/secure/store?data=...

A05 — Injection (SQLi) CWE-89

PROBLEMUser input concatenated into SQL — ' OR '1'='1 dumps all rows. 
GET /a05/vuln/search?username=' OR '1'='1
SOLUTIONBound ? parameter — the payload is treated as data. 
GET /a05/secure/search?username=...

A06 — Insecure Design CWE-840

PROBLEMDiscount code with no single-use and no rate limit (business-logic abuse). 
POST /a06/vuln/redeem?code=...
SOLUTIONAtomic single-use (409 on reuse) + fixed-window rate limit (429). Design the control in. 
POST /a06/secure/redeem?code=...

A07 — Authentication Failures CWE-287 / CWE-307

PROBLEMPlaintext password compare, user enumeration, no lockout, weak long-lived token. 
POST /a07/vuln/login?username=..&password=..
SOLUTIONBCrypt verify, uniform error, lockout after 5 fails (423), short-lived HS256 JWT (strong key). 
POST /a07/secure/login?username=..&password=..

A08 — Software / Data Integrity Failures CWE-502

PROBLEMNative Java ObjectInputStream deserialization of untrusted bytes (gadget-chain RCE). 
POST /a08/vuln/import     # body: base64 java-serialized
SOLUTIONHMAC-SHA256 verified (constant time) before parsing, then bound to a known DTO only. 
POST /a08/secure/import    # body: signed JSON

A09 — Security Logging & Alerting Failures CWE-778 / CWE-532

PROBLEMMoney transfer with no audit trail (and naive "log everything" would leak the PAN). 
POST /a09/vuln/transfer?to=..&amount=..
SOLUTIONStructured audit event (who/what/when/outcome), PAN masked, alert over a threshold. 
POST /a09/secure/transfer?to=..&amount=..

A10 — Mishandling of Exceptional Conditions CWE-209 / CWE-636

PROBLEMRaw stack trace returned; access check fails open (exception → access granted). 
GET /a10/vuln/divide?a=..&b=..   ·   /a10/vuln/access
SOLUTIONValidate input, generic error; fail closed; log details under a correlation id only. 
GET /a10/secure/divide?a=..&b=..  ·   /a10/secure/access

Roadmap gap-demos

SpEL Injection CWE-917

PROBLEMUser input parsed with the default SpEL context — type refs & method calls reachable (RCE). 
GET /roadmap/spel/vuln/eval?expr=T(java.lang.Runtime)
SOLUTIONArithmetic allow-list + SimpleEvaluationContext.forReadOnlyDataBinding() — no type access. 
GET /roadmap/spel/secure/eval?expr=7*7

LDAP Injection CWE-90

PROBLEMInput concatenated into the search filter — metacharacters rewrite it and bypass the password term. 
GET /roadmap/ldap/vuln/login?user=*)(uid=*&password=x   # authenticated=true
SOLUTIONEscape every value per RFC 4515 (or use LdapQueryBuilder) — metacharacters become inert. 
GET /roadmap/ldap/secure/login?user=alice&password=alice123

Open Redirect CWE-601

PROBLEMRedirect target taken from user input — sends victims off-site from a trusted link. 
GET /roadmap/openredirect/vuln/go?next=https://evil.example   # 302 off-site
SOLUTIONAllow-list of in-app paths; reject absolute and protocol-relative //host targets. 
GET /roadmap/openredirect/secure/go?next=/roadmap            # 400 for external

Session Fixation & Cookie Flags CWE-384 / CWE-1004 / CWE-614

PROBLEMSession id not rotated on login (fixation); cookie set without HttpOnly/Secure/SameSite. 
POST /roadmap/session/vuln/login?user=alice   # sessionIdChanged=false
GET  /roadmap/session/vuln/set-cookie        # SID=... (no flags)
SOLUTIONRotate id with changeSessionId(); set HttpOnly; Secure; SameSite=Strict. 
POST /roadmap/session/secure/login?user=alice  # sessionIdChanged=true
GET  /roadmap/session/secure/set-cookie

Actuator Exposure CWE-200

PROBLEMActuator wide open — /env leaks the JWT secret; /beans,/mappings,/heapdump exposed. 
GET /actuator/env   /actuator/beans   /actuator/mappings
SOLUTIONExpose only health/info; ADMIN-gate /actuator/**; separate mgmt port. See ActuatorSecurityNotes. 
GET /roadmap/actuator/explain

DAST points

Insecure HTTP Methods CWE-650

PROBLEMRead-only resource answers PUT/DELETE/any verb (no method restriction). 
curl -X DELETE /roadmap/dast/httpmethods/vuln/resource   # 200 (bad)
SOLUTIONMap only the verb implemented (@GetMapping) — others get 405. Disable TRACE. 
curl -X DELETE /roadmap/dast/httpmethods/secure/resource # 405

Cacheable Sensitive Data CWE-525

PROBLEMPrivate balance served Cache-Control: public, max-age=3600 — proxy/CDN/browser can store it. 
curl -i /roadmap/dast/cache/vuln/balance
SOLUTIONSend Cache-Control: no-store, no-cache, must-revalidate on sensitive responses. 
curl -i /roadmap/dast/cache/secure/balance

Secret in URL / Query String CWE-598

PROBLEMReset token in the query string — leaks via access logs, browser history, Referer. 
POST /roadmap/dast/url/vuln/reset?token=SECRET-123&newPass=p
SOLUTIONCarry the secret in a header (or POST body); keep the URL clean. 
POST /roadmap/dast/url/secure/reset  -H "X-Reset-Token: SECRET-123"

CRLF / HTTP Response Splitting CWE-113

PROBLEMUser input reflected into a response header — \r\n can inject headers / split the response. 
GET /roadmap/dast/crlf/vuln/echo?value=hello%0d%0aSet-Cookie:%20x=1
SOLUTIONStrip CR/LF and control chars before the value reaches any header (defence in depth). 
GET /roadmap/dast/crlf/secure/echo?value=...
